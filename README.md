# سلم

منصة مصرية لحجز سيشنز مجانية تساعد المبرمجين والخريجين يطوروا مهاراتهم ويجهزوا للخطوة الجاية في مجال التِك. مبنية بـ React وVite ومتكاملة مع Clerk.

## التشغيل

```bash
cp .env.example .env.local
npm install
npm run dev
```

حط مفتاح Clerk القابل للنشر في `VITE_CLERK_PUBLISHABLE_KEY`. من غير المفتاح، الموقع بيشتغل في وضع المعاينة.
